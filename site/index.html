To control the tank from your phone:
  1. Turn OFF Mobile Data & Private DNS in phone settings so traffic routes to the tank.
  2. Connect phone Wi-Fi to PanzerTank-AP (Password: panzer123456).
  3. If phone says "Connection failed", tap Forget Network, then reconnect and enter password panzer123456 with WPA/WPA2 security.
  4. If phone asks "Wi-Fi has no internet", tap Keep Wi-Fi Connection / Stay Connected.
  5. If phone DHCP fails or hangs, set IP settings: Static / Manual:
    IP: 192.168.4.50 • Gateway: 192.168.4.1 • Prefix Length: 24 (or Subnet: 255.255.255.0) • DNS: 192.168.4.1
